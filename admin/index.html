Connect your GitHub repository

This panel saves your work straight into the repository that hosts your site. Your access token is stored only in this browser.

How to create an access token
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens, then choose Generate new token.
  2. Give it a name and an expiry date.
  3. Under Repository access, choose Only select repositories and pick your portfolio repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate the token, copy it and paste it above. GitHub only shows it once.
